# Gestão Estratégica de Pessoas · V3 (homologação)

Pasta completa para implantação no HUB COMLURB. Copiar o **conteúdo desta pasta `pessoas/`** para `COMLURB/pessoas/`, substituindo os arquivos correspondentes.

Arquivos de produção: `index.html`, `pessoas.css`, `pessoas.js`, `resumo-publico.js`.

Essa versão elimina a segunda chamada grande do título abaixo do cabeçalho oficial e inclui uma barra de contexto/competência. Confirme no navegador o rótulo `PAINEL CORPORATIVO` no início do conteúdo para verificar a publicação.

Mantenha os arquivos compartilhados do HUB sob `assets/`, sem alterá-los.

Dados agregados e estáticos para homologação. Não inserir dados individualizados. A publicação precisa de aprovação de privacidade.

Se existirem `app.js`, `data.js` e `screens.js` legados na pasta publicada, não são utilizados por esta versão. Não publicar qualquer fonte individual sensível.
